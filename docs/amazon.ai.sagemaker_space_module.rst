*************************
amazon.ai.sagemaker_space
*************************

**Manage Amazon SageMaker AI Spaces**


Version added: 2.0.0

.. contents::
   :local:
   :depth: 1


Synopsis
--------
- Create, update, and delete Amazon SageMaker AI Spaces.
- Spaces are created within a SageMaker Domain.



Requirements
------------
The below requirements are needed on the host that executes this module.

- python >= 3.9
- boto3 >= 1.35.0
- botocore >= 1.35.0

Notes
-----

.. note::
   - Required IAM actions include sagemaker:CreateSpace, sagemaker:DescribeSpace, sagemaker:UpdateSpace, sagemaker:DeleteSpace, sagemaker:ListTags, sagemaker:AddTags, and sagemaker:DeleteTags.
   - Space creation, updates, and deletion are asynchronous lifecycle operations.
   - **Caution:** For modules, environment variables and configuration files are read from the Ansible 'host' context and not the 'controller' context. As such, files may need to be explicitly copied to the 'host'.  For lookup and connection plugins, environment variables and configuration files are read from the Ansible 'controller' context and not the 'host' context.
   - The AWS SDK (boto3) that Ansible uses may also read defaults for credentials and other settings, such as the region, from its configuration files in the Ansible 'host' context (typically ``~/.aws/credentials``). See https://boto3.amazonaws.com/v1/documentation/api/latest/guide/credentials.html for more information.

Examples
--------

.. code-block:: yaml

    - name: Create a SageMaker Space
      amazon.ai.sagemaker_space:
        domain_id: "d-0123456789ab"
        space_name: "ml-engineering"
        space_display_name: "ML Engineering"
        space_settings:
          app_type: "JupyterLab"
          space_storage_settings:
            ebs_storage_settings:
              ebs_volume_size_in_gb: 16

    - name: Update Space tags
      amazon.ai.sagemaker_space:
        domain_id: "d-0123456789ab"
        space_name: "ml-engineering"
        tags:
          environment: "production"
          team: "ml-platform"

    - name: Delete a SageMaker Space
      amazon.ai.sagemaker_space:
        domain_id: "d-0123456789ab"
        space_name: "ml-engineering"
        state: absent
