.. _amazon.ai.sagemaker_user_profile_module:


********************************
amazon.ai.sagemaker_user_profile
********************************

**Manage Amazon SageMaker AI user profiles**


Version added: 2.0.0

.. contents::
   :local:
   :depth: 1


Synopsis
--------
- Creates, updates, and deletes Amazon SageMaker AI user profiles in an existing domain, and manages their tags.
- A user profile is the identity of a user inside a SageMaker AI domain. It holds the execution role and the Studio, app, storage, and file system settings of the user.



Requirements
------------
The below requirements are needed on the host that executes this module.

- python >= 3.9
- boto3 >= 1.38.0
- botocore >= 1.38.0

Notes
-----

.. note::
   - Required IAM actions include sagemaker:CreateUserProfile, sagemaker:DescribeUserProfile, sagemaker:UpdateUserProfile, sagemaker:DeleteUserProfile, sagemaker:ListUserProfiles, sagemaker:ListTags, sagemaker:AddTags, and sagemaker:DeleteTags.
   - Setting O(execution_role) or another IAM role ARN may also require iam:PassRole on that role.
   - A user profile can only be deleted after all apps and spaces it owns are deleted. This module does not delete them.
   - O(domain_id), O(user_profile_name), O(single_sign_on_user_identifier) and O(single_sign_on_user_value) cannot be changed on an existing user profile.
   - With O(state=present), the module fails for a user profile that is being deleted or whose creation or deletion failed. Use O(state=absent) to remove a failed user profile.
   - Lists of strings are compared as sets, and lists of dictionaries are compared without regard to order.
   - When a dictionary option differs, the module sends its current value merged with the supplied suboptions, so suboptions that are omitted keep their current value.
   - **Caution:** For modules, environment variables and configuration files are read from the Ansible 'host' context and not the 'controller' context. As such, files may need to be explicitly copied to the 'host'.  For lookup and connection plugins, environment variables and configuration files are read from the Ansible 'controller' context and not the 'host' context.
   - The AWS SDK (boto3) that Ansible uses may also read defaults for credentials and other settings, such as the region, from its configuration files in the Ansible 'host' context (typically ``~/.aws/credentials``). See https://boto3.amazonaws.com/v1/documentation/api/latest/guide/credentials.html for more information.

Examples
--------

.. code-block:: yaml

    - name: Create a user profile with the default settings of the domain
      amazon.ai.sagemaker_user_profile:
        domain_id: "d-xxxxxxxxxxxx"
        user_profile_name: "my-user"

    - name: Create a user profile with custom settings and tags
      amazon.ai.sagemaker_user_profile:
        domain_id: "d-xxxxxxxxxxxx"
        user_profile_name: "my-user"
        execution_role: "arn:aws:iam::123456789012:role/SageMakerExecutionRole"
        default_landing_uri: "studio::"
        studio_web_portal: "ENABLED"
        auto_mount_home_efs: "DefaultAsDomain"
        sharing_settings:
          notebook_output_option: "Allowed"
          s3_output_path: "s3://my-bucket/sharing/"
        jupyter_lab_app_settings:
          default_resource_spec:
            instance_type: "ml.t3.medium"
          app_lifecycle_management:
            idle_settings:
              lifecycle_management: "ENABLED"
              idle_timeout_in_minutes: 120
          code_repositories:
            - repository_url: "https://github.com/example/repo.git"
        space_storage_settings:
          default_ebs_storage_settings:
            default_ebs_volume_size_in_gb: 5
            maximum_ebs_volume_size_in_gb: 100
        tags:
          team: "data-science"

    - name: Change only the default JupyterLab instance type, keeping the other JupyterLab settings
      amazon.ai.sagemaker_user_profile:
        domain_id: "d-xxxxxxxxxxxx"
        user_profile_name: "my-user"
        jupyter_lab_app_settings:
          default_resource_spec:
            instance_type: "ml.m5.large"

    - name: Add a tag without removing the existing ones
      amazon.ai.sagemaker_user_profile:
        domain_id: "d-xxxxxxxxxxxx"
        user_profile_name: "my-user"
        tags:
          owner: "alice"
        purge_tags: false

    - name: Delete a user profile without waiting for the deletion to finish
      amazon.ai.sagemaker_user_profile:
        state: "absent"
        domain_id: "d-xxxxxxxxxxxx"
        user_profile_name: "my-user"
        wait: false
